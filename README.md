# 🚗 Car Animation Game

A fun and interactive **Car Animation Game** built using **HTML, CSS, and JavaScript**.

The project features a moving car, rotating wheels, animated road and trees, background scenery, car movement effects, and background sound.

## 🚀 Live Demo

👉 **[Play Car Animation Game](https://techanuruddh.github.io/Car-Animation-Game-/)**

## ✨ Features

* 🚗 Animated car movement
* 🔄 Rotating car wheels
* 🛣️ Moving road animation
* 🌳 Animated trees and background
* 🎵 Background sound
* 📱 Responsive viewport support
* ⚡ Smooth CSS animations
* 🌐 Deployed using GitHub Pages

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Animations, styling and visual effects
* **JavaScript** — Audio interaction
* **Git & GitHub** — Version control and hosting
* **GitHub Pages** — Live deployment

## 🎮 How to Play

1. Open the live demo.
2. Wait for the animation to load.
3. Enjoy the moving car and animated environment.
4. Click on the page once to start the background sound.
